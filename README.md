# 🥤 Mi Tienda de Shake

¡Bienvenido a **Mi Tienda de Shake**! Este es un sitio web creado para ofrecer batidos y shakes deliciosos y saludables, utilizando ingredientes andinos y frutas frescas.

## 🚀 Características
* **Índice interactivo:** Navegación fluida por el menú.
* **Diseño visual:** Incluye imágenes de alta calidad para cada batido (como Mango, Fresa Andina, Quinoa, etc.).
* **Interactividad:** Scripts en JavaScript para mejorar la experiencia del usuario.

## 🛠️ Tecnologías utilizadas
* **HTML5** - Estructura de la página (`índice.html`).
* **JavaScript** - Funcionalidades dinámicas (`script.js`).
* **Markdown** - Para esta documentación.

## 📂 Archivos del proyecto
En este repositorio encontrarás la estructura básica, el código lógico y una carpeta de imágenes con los ingredientes principales (Plátano, Kiwicha, Fresa, etc.).
